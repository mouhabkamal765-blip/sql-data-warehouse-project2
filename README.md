Data Warehouse and Analytics Project
Welcome to the Data Warehouse and Analytics Project repository!
This project demonstrates a comprehensive data warehousing and analytics solution, from building a robust data warehouse to generating actionable insights. Designed as a portfolio project, it highlights industry best practices in data engineering and analytics
Project Requirements
Objective: Develop a modern data warehouse using SQL Server to consolidate sales data, enabling analytical reporting and informed decision-making .

Data Sources: Import data from two source systems—ERP and CRM—provided as CSV files inside a folder .

Data Quality: Clean and fix data quality issues (such as messy or incomplete raw data) before conducting any analysis .

Integration: Combine multiple source systems into a single, user-friendly data model optimized for reporting and analytics .

No Historization: Focus exclusively on the latest datasets without needing to build historical tracking into the database .

Documentation: Provide clear documentation and manuals of the final data model to support business users and analytical teams .
